Sou desenvolvedor web com foco em **aplicações full stack**, **landing pages**, **dashboards administrativos**, **sistemas para negócios reais** e uso estratégico de IA para acelerar desenvolvimento, prototipagem e automação.

Tenho interesse especial por produtos digitais que unem três coisas raras: aparência forte, fluxo funcional e utilidade comercial. Porque uma interface bonita sem lógica é só decoração — e um sistema poderoso sem apresentação é um segredo enterrado onde ninguém procura.

Atualmente desenvolvo projetos sob a marca **Lunaris**, com foco em soluções web para restaurantes, negócios locais, portfólios, landing pages e sistemas personalizados.
